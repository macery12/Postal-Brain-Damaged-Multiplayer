# Development status

Current development: **PBDMP 0.10.0 / protocol 10 / save schema 2**. The last accepted baseline is 0.9.0; this page is not a published-release announcement.

PBDMP supports two-player base-campaign co-op through Steam lobbies/relay or Direct IP, with host-owned campaign travel, enemies/combat and shared world adapters. Player health, armor, pickups and non-ammo resources follow the personal-resource rules. Host-owned co-op saves and checkpoint rollback use separate storage, named slots, quicksave, rotating autosaves, recovery backups and partner assignment. P2 catches up to P1's weapons/ammo on joins/restores.

The [world megapass](../megapass.md#current-remaining-work) remains in progress. Its first acceptance-closing batch verifies secrets/counts/rollback/rejoin, partly elapsed barrel fuses, requester teleportation with native momentum, cannon target/victim behavior and state-aligned strict Prison comparisons. It fixes invisible ownerless scenery projectiles and a persistent-capture publishing gap that could leave live changes missing on P2. Native fixtures, repeated saves and campaign catalogue audits support those results; meaningful natural routes and the remaining machinery/hazard/recovery checks retain their explicit closing rows.

Use the [granular sync tracker](sync-progress.md) for feature status, [verification](verification.md) for evidence and reproduction commands, [co-op saves](co-op-saves.md) for storage/player rules and [roadmap](roadmap.md) for later milestones. Current status takes precedence over dated research/checkpoint notes.

The physical-restoration follow-up prevents stale display transforms from replacing saved rigidbody poses and restores bodies after parent machinery. Active-prop pooling/rejoin, shifted-arena, native save/restore and strict Prison checks pass. The remaining megapass list now contains eleven partial acceptance areas. Both Area69 conveyor arrays, personal gravity contacts and Hospital pusher attribution pass. Native beam/line/urine presentation passes after removing repeated scene searches. The latest extended elevator ride still records a P2 death/respawn; FPS and network performance remain major open work. Development coverage is 93% with explicit partial credit; the last accepted baseline remains 90%.
